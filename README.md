# chiche! · médias publics

Les médias publiés sur les réseaux de chiche! (images, carrousels, vidéos), mis en ligne par Meringue, le studio de l'agence chiche!, pour que Metricool puisse les récupérer.

Servi par GitHub Pages : https://playwithchiche.github.io/chiche-medias/
Un dossier par mois : `AAAA-MM/<id du contenu>-<n>.<ext>`. Rien d'autre que des médias publiables.
