# chiche! · médias publics

Les médias publiés sur les réseaux de chiche! (images, carrousels, vidéos), mis en ligne par Meringue, le studio de l'agence chiche!, pour que Metricool puisse les récupérer.

Servi par GitHub Pages : https://playwithchiche.github.io/chiche-medias/
Un dossier par mois : `AAAA-MM/<id du contenu>-<n>.<ext>`. Rien d'autre que des médias publiables.

## Bibliothèque (sources de montage, pas des publications)
`bibliotheque/` contient des éléments que Meringue intègre dans ses montages, jamais publiés tels quels.
- `bibliotheque/reactions/` : les 16 vidéos réactions du double IA de Ludmila (Higgsfield, 4 nov. 2026), `avatar-V01.mp4` à `avatar-V41.mp4`, 3 s, 1080 × 1920, muettes, et `planche.jpg` (4 images de chaque). Mode d'emploi : `docs/videos-reactions.md` du dépôt chiche-agence.
